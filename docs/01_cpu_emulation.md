# 1. CPU Emulation

## 1-1. Register

- CPU 레지스터는 프로세서 내부에 위치한 매우 빠른 소형 저장 공간.
- 게임보이 CPU 레지스터는 8비트 레지스터와 16비트 레지스터를 가지고 있음.
  - 8비트 레지스터
    - A: 누산기 (Accumulator) - 계산 결과를 저장
    - B, C, D, E, H, L - 범용 레지스터
    - F: 플래그 레지스터 - 연산 결과의 상태를 나타내는 플래그를 보관
  - 16비트 레지스터
    - PC (Program Counter): 다음에 실행될 명령어의 메모리 주소
    - SP (Stack Pointer): 스택의 최상단 주소
    - 레지스터 페어: 8비트 레지스터를 결합

### 1-1. 임시 데이터 저장소

- 레지스터는 기본적으로 CPU가 즉시 접근 할 수 있음. 따라서 현재 처리중인 데이터나 중간 계산 결과를 저장하는데 사용됨.

- 예를 들어, 두 값을 더하는 연산을 실행한다고 가정하면
  - A 레지스터(누산기)에 첫번째 값을 로드
  - 다른 레지스터나 메모리에서 두번째 값을 로드하여 더함
  - 결과를 다시 A 레지스터에 저장

### 1-2. 프로그램 실행 제어

- 특수 레지스터(PC, SP)들은 프로그램의 실행 흐름을 제어함.

- PC(Program Counter): 다음에 실행할 명령어의 메모리 주소를 저장. CPU는 해당 값을 참조하여 명령어를 가져오고, 명령어 실행 후 PC 값을 증가시켜 다음 명령어로 진행.
  - 분기(branch)나 점프(jump) 명령은 PC값을 직접 변경하여 프로그램 흐름을 제어
- SP(Stack Pointer): 스택의 최상단 주소를 지칭. 함수 호출시 반환 주소를 저장하거나, 임시 데이터를 스택에 푸시할 때 사용. 게임보이에서는 특히 인터럽트 처리나 함수 호출에서 중요하게 사용.

### 1-3. 연산 상태 추적 (플래그 레지스터)

플래그 레지스터 (F)는 마지막 연산 결과에 대한 중요한 정보를 비트 단위로 저장함.

- Z Flag: 연산 결과가 0인지 나타냄.
- Carry (c) Flag: 연산결과가 8비트 범위 (0-255)를 초과했는지 나타냄.
- Half-Carry (H) Flag: 하위 4비트에서 자리올림이 발생했는지 나타냄.
- Subtract (N) Flag: 마지막 연산이 뺄셈이었는지 나타냄.

### 1-4. 특화된 연산 지원

- BC, DE, HL 레지스터 쌍: 16비트 주소를 저장, 처리. 블록 전송 명령에서 카운터로 사용
- AF: 누산기 & 플래그 쌍
